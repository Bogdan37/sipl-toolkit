# SIPL Language Toolkit (.NET / C#)

Інструментарій для навчальної мови програмування **SIPL** (SImple Programming Language) у межах курсового проєкту з дисципліни «Теорія програмування».

## Обрані модулі та розрахунок балів

| ID | Модуль | Бали | Статус |

| `CORE-01` | Формальна специфікація SIPL (EBNF, лексика, позитивні/негативні приклади) | 0.5 | В роботі |
| `CORE-02` | Парсер та типізоване AST з `SourceSpan` | 1.5 | Заплановано |
| `CORE-03` | Інтерпретатор SIPL з лімітом кроків та тестами ($\ge 80\%$) | 2.0 | Заплановано |
| `CORE-04` | Подієва модель виконання та JSON-трасування (`trace`) | 1.0 | Заплановано |
| `CORE-05` | CLI (`parse`, `check`, `run`, `trace`) з підтримкою `--json` | 1.0 | Заплановано |
